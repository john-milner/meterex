## Supported Versions

| Version | Supported |
|---|---|
| 2.x     | yes       |
| 1.x     | no        |
| 0.x     | no        |

## Reporting a Vulnerability

Please report suspected vulnerabilities privately to `security@milner.dev` rather than opening a public issue.

Include:

- A description of the issue
- Steps to reproduce
- Impact assessment
- Any suggested mitigation

We aim to acknowledge reports within 72 hours.ggdG
