# Contributing to metrex

Thanks for your interest. Here's how to get started.

## Setup

```bash
git clone https://github.com/john-milner/meterex.git
cd meterex
npm install
```

## Running locally

```bash
npm run dev
```

## Tests

```bash
npm test
```

## Lint

```bash
npm run lint
```

## Pull requests

- Keep changes focused on a single concern
- Update `CHANGELOG.md` under a new "Unreleased" section
- Add tests for new behavior
- Run `npm run lint && npm test` before submitting

## Reporting bugs

Open an issue with:

- Steps to reproduce
- Expected behavior
- Actual behavior
- Node version and OS
